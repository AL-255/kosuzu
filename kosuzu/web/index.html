MAKE IT YOUR WORKSPACE
Connections & settings
Your keys stay in this program's private local state. They never enter the inventory repository.
    Where your inventory lives
    Create a separate GitHub repository and invite collaborators. Kosuzu can initialize an empty repository for you. Already joining a workspace? Use the repository and branch your administrator gave you.
    Your access key signs you into Kosuzu. GitHub tokens let Kosuzu submit requests and update inventory.
    Advanced: approved LLM hosts
    Save settings first. Existing inventory is preserved.
    Your client connection
    Use your own token restricted to the inventory repository: Contents and Pull requests read/write, Commit statuses read. The server needs its own token with those three permissions set to read/write.
    Create a fine-grained GitHub token ↗ · Detailed setup instructions ↗
    Blank credential fields keep saved keys. Sign out removes this browser profile's credentials; queued requests remain in local state.
    How you review a part
    You can check details yourself with no LLM key. If you enable LLM review, supplier data is sent to your provider to normalize fields and flag inconsistencies.
    Every path requires your confirmation. Use the manufacturer datasheet to check electrical specifications.
    Choose your suppliers
    No supplier keys yet? LCSC and Adafruit use public pages. Other suppliers can try public pages, although some websites block lookups. Manual part entry is always available.
    Ready for your first component
    Check the saved GitHub connection before finishing. If this is a new inventory repository, initialize it first; existing inventory is preserved.
    Stock requests wait for the Linux server to apply them. Desktop clients do not merge requests.
